# École Champlain Redesign Prototype

Clickable React/Vite prototype for a high-end modernization of the public École Champlain website.

## Run

```powershell
npm install
npm run dev
```

## Content Source

- `content-source/scraped-pages.json` contains the scraped public-site source data.
- `src/content.ts` is generated from that source with obvious typos and stale labels cleaned.
- `public/assets` contains downloaded public Champlain/DSFS assets.
- `public/concepts` contains the generated concept images used as the visual spec.
