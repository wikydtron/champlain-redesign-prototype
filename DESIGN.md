# Design

## System

The prototype uses a brand-register visual system inspired by the generated concepts in `public/concepts`: a deep navy institutional base, Champlain green as the primary action color, Acadie red/yellow accents, wave/book-line motion, compass/star motifs, and large recognizable logo placement.

## Color

- Navy: `#00264d`
- Deep navy: `#001a35`
- Champlain green: `#006a4e`
- Green light: `#7ac143`
- Acadie red: `#d01925`
- Acadie yellow: `#f4b400`
- Ink: `#071a33`
- Paper: `#fbfaf7`
- White: `#ffffff`

## Typography

- Display: Alegreya, Georgia, serif fallback
- Body/UI: Fira Sans, system sans fallback
- Headings use balanced wrapping and strong line-height control.
- Body copy is capped for comfortable French reading.

## Components

- Logo masthead with utility strip and dropdown navigation.
- Parent quick-action rail.
- Editorial news rail.
- Deep navy values band.
- Tactile school-life rows.
- Search overlay.
- Mobile drawer navigation.
- Content article view with side navigation, image gallery, source link, and related links.

## Motion

Wave-line draw, staggered entrance, hover underlines, menu drawer transitions, and image-frame parallax cues. Reduced motion disables transforms and long-running animation.
